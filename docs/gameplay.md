# 玩家指南

带着暖暖散步、照料小动物、回家做饭，按自己的节奏过一天。活动菜单会显示当前地点能做的事；选一个动作后，暖暖通常会先走到对应位置再开始。

启动游戏见 [README.md](../README.md)。iPad 安装与运行见 [README.md](../iPadApp/README.md)。

## 第一次游玩

1. 关闭欢迎说明，点一块地面，看看暖暖怎么绕过树和围栏。
2. 在农场采花、喂动物，或走到池塘边试试钓鱼。
3. 从活动菜单选择「开门回家」，探索衣柜、厨房、浴缸和阳台。
4. 想接布偶猫回家，先在卧室拿猫旅行包，再去村庄寄养所。
5. 玩累了到饭桌吃饭；中午可睡午觉，晚上播放「月光摇篮曲」再上床。

网页刷新会重新开始生活状态；图鉴记录另行保留。iPad 会自动保存完整检查点，详见最后的保存说明。

## 操作

### 网页版

| 操作 | 用法 |
| --- | --- |
| 移动 | 方向键或 `W` / `A` / `S` / `D` |
| 自动寻路 | 点击地面，或从活动菜单选择目的地 |
| 小跑 | 移动时按住 `Shift` |
| 附近互动 | 按 `E`，或点击画面下方的动作按钮 |
| 多个邻近动作 | 根据并排提示选择 `E` / `R` / `T` / `Y` |
| 放下宠物或松绳 | 按 `Q`，或按住 `E` 约 0.65 秒；短按 `E` 仍可互动 |
| 钓鱼收线 | 按住 `E` 或收线按钮；拉力变红时松开 |
| 秋千用力 | 按住空格或用力按钮 |
| 结束动作 | 点击当前结束按钮；许多动作也可按 `Esc` |

手动移动会取消自动路线。睡觉、洗澡、沙发、钓鱼和秋千等动作有自己的结束流程；有的会先收竿、穿衣或停稳，再允许继续移动。以当前按钮和提示为准。

右上角「☰ 活动」打开地点导航、背包、图鉴与照料菜单。选好动作后菜单会收起。树、家具、围栏和动物需要绕行，不能攀爬或穿过。

### iPad 版

点地面移动，走近后点动作按钮。iPad 不显示常驻方向键和小跑按钮；钓鱼、秋千等需要按住操作的按钮会按需出现。

- 「停一下」取消路线或请求结束当前动作；秋千仍需慢慢停稳。
- 「放下 / 松绳」结束携带宠物或遛狗。
- 活动列表可以滑动，也有「往上翻」「往下翻」按钮。
- 「‹ 首页」回到原生首页并暂停游戏，再进入可继续当前会话。

左上角的小肚子和干净度，越满越舒服。吃饭和零食补充小肚子，洗澡恢复干净度；饿了会提醒，不会强制中断当前活动。

## 出门探索

| 地点 | 可以做什么 |
| --- | --- |
| 农场 | 采花、喂食、抚摸动物、钓鱼、骑马、秋千、捡树叶 |
| 养殖场 | 从农场门口进入，查看和照料棚内动物 |
| 岔路口 | 左边去森林，前面去村庄或朋友聚会，右边去集市 |
| 森林 | 采蘑菇、捡树叶、捕虫、收集木材，与松鼠、兔子和小鹿亲近 |
| 朋友聚会 | 打招呼、送花、分享食物；右侧小路也通往城市集市 |
| 城市集市 | 买面包、领果蔬和花束、认识居民，进入医院、面包店和宠物医院 |
| 村舍 | 从朋友聚会的门口进入拜访，再从门口返回 |
| 寄养所 | 从医院和面包店之间的楼梯进入，寄养或接回自家猫狗 |

「村庄」「城市」「集市」的入口通往同一张集市地图。离开森林、聚会或集市时，选择返回会先走到本图出口；回到岔路口后，再沿回农场的小路走。公共建筑从门口退出，返回原来的门附近。寄养所的楼梯入口和室内出口也能步行通过。

森林的采集点有冷却时间，蘑菇采走后会在其他位置重新长出。捕虫和收集木材需要完成动作才入包；先下马、放下怀里的伙伴再开始这些活动。

认识朋友需要主动打招呼或赠送礼物。只是进地图、走到朋友旁或打开聊天面板，不会增加好友。礼物使用背包中已有的花或食物；已认识的朋友也可能出现在集市。

## 农场动物、骑马和秋千

农场每天提供饲料，每只动物每天接受一次喂食。重复喂同一只不会继续长大；成体保持大小，羔羊在满足每日喂养条件后，会在之后的游戏日逐渐成长。抚摸可以增进感情，长期不陪伴或恶劣天气中疏于照料会降低感情。

羊、猪、牛和鸡留在农场自己的活动区域，可喂食和抚摸。只有小马可以骑到其他室外地图；猫狗的携带与遛狗使用另一套照料规则。

选择「骑马」后，暖暖先经过围栏门，再走到真实的小马旁上马。马停下时保持站姿，下马后留在当前地点。窄楼梯、水边和室内通道需要先下马；动物堵住门口时，等它们让开再试。

粉裙、蓝裙和羽绒服可用于骑马、钓鱼和秋千。穿睡衣或浴袍时会提示先换外出衣服，动作不会替你直接换成另一套裙子。

荡秋千时按住用力，松开后自然减速。选择结束会等待停稳再下来。

## 钓鱼

1. 从农场活动选择「池塘钓鱼」，走到桥边抛竿。
2. 等浮漂明显沉下去。鱼试探鱼饵时不要提前提竿。
3. 提示咬钩后，按 `E` 或点提竿按钮。
4. 按住 `E` 或收线按钮。拉力变红时松开一下，再继续收线。
5. 成功钓上来的鱼放进背包，并显示鱼种和大图；看完手动关闭。

提竿过早、错过咬钩或拉力过高都会让鱼逃走。等待咬钩通常为 4–8 秒；网页可走开或按 `Esc` 收竿，iPad 可用「停一下」。钓到的鱼能做饭，也会记入图鉴。

## 布偶猫和萨摩耶

### 接猫、同行和寄养

布偶猫开局住在寄养所左侧的蓝色软垫。先回家拿旅行猫包，再沿集市中医院和面包店之间的楼梯上楼，选择接回布偶猫。四只常驻猫是橘猫，自家的布偶猫和寄养的萨摩耶会显示「我的」。

猫包随身携带，空包可以回卧室放下。有猫包才能把布偶猫抱进包里；宠物必须在当前地图，才能照料。可从「抱抱和照料」选择抱、背、上床和洗澡。照料中的宠物会暂停自主活动。

遛萨摩耶时，狗跟随暖暖跨地图散步。短按 `E` 可以继续与周围物件互动，长按 `E` 或按 `Q` 松绳；活动菜单里的「松开萨摩耶牵绳」也能在原地使用。可以同时提着猫包、牵着狗回家。

寄养狗需要先牵到寄养所，寄养猫需要先用猫包带来。寄养后它们留在所内，回来再办理接回；忘带猫包时不会强行把猫接走。健康狗夜间不开始新散步，病狗仍可牵去看兽医。

寄养所也可以用空猫包接一只常驻橘猫去宠物医院检查，检查完成后带回寄养所安顿。

### 日常照料

猫狗食盆、储粮盆、猫砂盆和狗尿垫在阳台。添粮时暖暖先舀粮，再走到对应食盆倒入；食盆可供多次进食，宠物吃完一份才减少库存。阳台门需要打开，宠物也不能穿过关闭的门板。

狗通常白天活动、夜间睡觉；布偶猫早上 6 点到中午 12 点休息，下午和夜间活动。作息、短盹、疾病和照料状态会影响接球、捕猎和散步；如果按钮提示休息，可以先做别的事。

布偶猫在附近或被带到床边时，可以跳上床脚陪暖暖睡觉。留在其他地图的猫不会自动传送回来。

## 在家生活

### 衣服、鞋袜和被子

衣柜可换粉裙、蓝裙、兔兔睡衣、浴袍和羽绒服，也能挑被子。换衣和换被子有拿取、行走与铺开的动作；选好后等暖暖完成。

鞋架可挑外出鞋、拖鞋和袜子。在家穿拖鞋，选好的外出鞋留到出门时换上。冬天打开衣柜会优先拿羽绒服，睡前仍会换睡衣。

### 厨房、用餐和冰箱

厨房可以做蔬菜饭、蘑菇汤、煎鱼和肉菜饭，分别需要一份对应原料。食材优先取自背包，没有时可直接取冰箱库存。蘑菇汤会先洗蘑菇，再回锅边煮。

做好的菜会端到饭桌，多份菜按完成顺序吃；多出的份数收进背包。端菜途中取消，会收好已经做好的饭。饭菜放下并休息一会儿后，空闲的暖暖会坐到餐椅上吃；也可主动选择饭桌吃饭。

初始冰箱有冰淇淋、冰沙、肉和鱼。走近柜子打开后，每次存取一份已有物品；取空了就不能继续取。拿出冰淇淋或冰沙也能到饭桌坐下吃。

| 食物所在位置 | 保鲜规则 |
| --- | --- |
| 冰箱内 | 持续保鲜 |
| 背包冰淇淋、冰沙 | 1 个游戏日 |
| 背包面包 | 2 个游戏日 |
| 背包水果、蔬菜、鱼、肉、熟饭、蘑菇 | 3 个游戏日 |

背包按获得批次记录鲜度，旧批次变质不会影响新批次。变质食物单独列出，不能吃或做饭，走到冰箱旁可以清理。未煮熟就取消做饭，原料会回到原来的储存位置，并保留原批次鲜度。

集市面包每份 2 金币，初始有 20 金币；打包完成才扣钱、入包。果蔬摊一次提供两份水果和一份蔬菜，花束摊也可领取小花束。

### 清洁、植物和客厅

卫生间可以洗手、洗澡和使用马桶。暖暖会提醒需要上厕所；倒计时开始后，需要自己控制她回家并走到马桶旁，再按互动，不会由菜单代走全程。没有及时赶到时，回衣柜换干净衣服；用完马桶记得洗手。

室内有九盆绿植，可点击或从「照顾盆栽」前往。缺水会逐渐变褐，长期不浇会枯死，枯死后需要换新苗。取消未完成的浇水不会补水。

客厅可坐沙发、看电视、打开节目单换节目。空调在客厅与卧室的隔墙上，点击或从菜单开关；夏天能让屋内凉快，阳台不制冷。窗帘可手动开关，夜间空闲时暖暖也会去关帘。

## 昼夜、睡觉和四季

游戏时间与真实时间不同。自然经过午夜或睡过一夜会推进一天，午觉不会推进日历。活动菜单可以查看时钟、季节天数，也可手动切换时段、季节和天气。

午觉可从菜单主动开始，中午在家空闲时也会自动睡一次。床头闹钟可选半小时、一小时或一个半小时午觉，以及早晨 7、8、9 点起床。午觉醒来仍是下午。

晚上上床需要「月光摇篮曲」实际开始播放。只选曲目、静音或音乐没有成功启动，会提示睡不着；午觉不需要摇篮曲。播放摇篮曲会让暖暖结束活动、回卧室、换睡衣、关帘并盖被睡觉，主动起床后换回「田园晨光」。睡着后关音乐不会把她叫醒。

午夜时，已开始的上床动作继续；还在家中的暖暖会回床睡到第二天中午。外出或在公共建筑只提醒回家休息，不会在地上睡倒。午夜睡眠不能靠移动或切图提前结束，可用画面中的「睡到第二天中午」继续到醒来流程。

开着衣柜、厨房菜单或其他选择界面时，自动午睡、用餐和拉帘会等待。准备睡觉和睡眠期间，人物说话和气泡会清除，起床后恢复聊天。

春、夏、秋、冬循环，季节持续数个游戏日。夏天开始可能连续炎热，冬天开始会连续下雪；其他时候天气随机变化。秋天冷风、秋雨、冬天寒冷和冰雹都可能影响健康。夏天持续穿羽绒服也会过热，应根据天气换衣或进屋。

## 生病和小药袋

暖暖感冒、被冰雹砸伤或不舒服时，去村庄医院找医生，等待检查完成。猫狗生病时，要实际带到城市宠物医院，让兽医检查；淋雨、雪、冰雹中的长期暴露和偶发疾病都可能让宠物生病。健康检查不会让原本健康的角色染病。

感冒和砸伤需要诊断后的疗程，回家、切图或中途离开诊疗不会直接治好。夏季过热有自己的医院休息流程，按照界面提示处理。

医生交付按病人名字分开的三天份小药袋，其中「星星恢复药水」和「云朵调养药水」都是游戏里的虚构药水：

1. 药在随身小药袋时，可以直接选择对应病人的药。
2. 如需冷藏，回家走近冰箱，主动把剩余药存进去。
3. 冰箱里的药需要先取出对应一瓶，再从小药袋使用；已取出但未用的药会保留，不能重复取同一瓶。
4. 每种药各在三个不同游戏日使用一次，每天每种最多一次。
5. 漏服只延后进度，已用次数保留；已用足三次的一种药停用，另一种继续补齐。

人药、猫药、狗药不能混用。选择宠物药后，暖暖会走近宠物，必要时轻声叫醒再喂；没走到、取消、异图或寄养时，不会提前扣药。暖暖睡觉或忙于其他动作时不能用药。疗程中新出现的不适需要复诊，原处方只对应原诊断。

## 背包、图鉴、音乐和保存

背包显示可用物品、食物、金币和药物。图鉴保存发现与捕获记录；吃掉鱼、用掉蘑菇或把花送人，不会删掉已经认识的条目。

第一次点击或按键后才能开始声音。右上角音符用于开关声音，曲目可以选择。页面切到后台会停止声音；iPad 返回首页也暂停时间与声音。

| 版本 | 离开后会保留什么 |
| --- | --- |
| 网页版 | 换地图保留本次生活状态；刷新重开。图鉴写入当前浏览器的本地存储，清除网站数据会删除记录 |
| iPad 版 | 回首页再进入继续当前会话；每五秒和进入后台时尝试保存完整检查点，完全关闭后从最近成功保存的检查点恢复 |

iPad 的做饭、洗澡、诊疗、睡眠和开门等未完成动作不会保存中间过程。想让最新进度落盘，先完成当前动作，再保持游戏空闲片刻。存档只在本机，不会自动同步到别的设备；卸载 App 会删除存档。

## 遇到提示怎么办

| 提示或现象 | 可以尝试 |
| --- | --- |
| 那里暂时走不到 | 换一块空地，检查门是否打开，等动物让开；窄路先下马 |
| 动作没有立即开始 | 看暖暖是否正在走近目标或结束上一动作，关闭当前选择面板 |
| 找不到布偶猫 | 先拿猫包去寄养所接回；宠物不会自动从其他地图回来 |
| 想抱猫却提示拿猫包 | 回家卧室拿旅行猫包；包里有其他猫时先安顿它 |
| 晚上睡不着 | 开启声音，让「月光摇篮曲」实际播放，再选择睡觉 |
| 不能做饭或送礼 | 查看背包和冰箱里的对应品类，变质食物不能用 |
| 今天的药不能再用 | 看该种药是否今天已用、已完成三次，或还在冰箱里未取出 |
| 没有声音 | 点击音符再试，确认 App 或浏览器在前台；睡眠期间暖暖不会说话 |
| iPad 进度回到了前一步 | 最近的动作可能还没形成完整检查点；完成动作后再等待自动保存 |

需要报告问题时，提供版本、地点、操作步骤和实际提示；开发验证方法见 [testing.md](testing.md)。
