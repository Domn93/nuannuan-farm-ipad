# 随 App 提供的字体

- 标题与按钮：站酷快乐体 ZCOOL KuaiLe，来源 [googlefonts/zcool-kuaile](https://github.com/googlefonts/zcool-kuaile)，许可见 [OFL.txt](OFL.txt)。
- 游戏菜单小图标：Noto Emoji，来源 [google/fonts](https://github.com/google/fonts/tree/main/ofl/notoemoji)，许可见 [NotoEmoji-OFL.txt](NotoEmoji-OFL.txt)。采用统一线描图标，避免依赖模拟器或设备是否安装系统 Emoji 字体。

字体均为本地资源，游玩不从网络下载。中文长说明继续使用系统字体，保持清晰。
