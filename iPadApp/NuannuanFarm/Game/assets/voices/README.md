# 暖暖的语音

当前记录未包含实际生成服务与输出再分发条款；这批 MP3 不自动适用代码 MIT 许可。待补依据见 [许可清单](../../../../../THIRD_PARTY_NOTICES.md)。

19 条游戏短句使用 `zh-CN-XiaoxiaoNeural` 柔和女声生成，语速 `-3%`，保持原音调。MP3 随游戏本地播放，不需要玩家联网，也不使用浏览器默认的机械音色。

短句与文件的对应关系在 `js/voices.js` 的 `nuannuanVoiceClips` 中维护。新增或修改短句时，同时更新音频和映射；不要用播放速度或升调伪造童声。关闭声音、离开地图或隐藏页面时，立即停止语音；播放失败仍显示文字，不堆积朗读队列。

钓鱼报喜使用 `fish-new`、`fish-big`、`fish-small` 和 `fish-again`，优先于随机闲聊。风的台词改为“风轻轻吹过来，好舒服呀。”，使用 `wind-gentle`；旧 `wind.mp3` 保留但不再引用。
